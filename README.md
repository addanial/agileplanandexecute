# Agile Plan and Execute — Coursera Peer-Graded Project

An educational Scrum/Kanban exercise: **Customer Service Management System**.

## Sprint 1 — Customer Service Core Features
Objective: plan and execute a first sprint for a small customer support platform. Stories include customer account, ticket creation, ticket tracking, service dashboard, and engineering debt.

## Workflow
Product Backlog → Sprint Backlog → In Progress → Review/QA → Done.

All issues use **As a ... I need ... So that ...** and **Given / When / Then** acceptance criteria. Each includes a story-point estimate and sprint classification.

## Evidence
The GitHub Issues are the source of truth for story assignment and progress. A separate GitHub Projects Kanban board must be created and made public for Coursera Task 1. This repository does not claim a board or milestone exists until those actions are verified.

Burndown data must be based on actual sprint snapshots. Example data, where used for practice, is marked as illustrative rather than actual sprint history.
